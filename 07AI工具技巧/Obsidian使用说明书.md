## 插件

### 1. 基础与网页剪藏
*   **Drag and Drop Sort**
    *   **核心功能**：突破原生文件列表只能按名称或时间排序的限制，实现像 OneNote 一样的目录自由拖拽与自定义混排。
*   **Local REST API**
    *   **核心功能**：在本地启动安全端口，让浏览器插件、外部 AI 智能体（如 Codex）直接读写本地库，是实现自动化剪藏与外部工具联动的基础。
*   **Bilibili Obsidian Clipper (及其他视频剪藏工具)**
    *   **核心功能**：在 B站视频页面直接抓取作者字幕或 AI 字幕，一键保存至本地库，彻底打通视频内容的本地化整理。
*   **Obsidian Web Clipper (官方/增强版)**
    *   **核心功能**：一键将任意网页（如微信公众号）提取为干净的 Markdown 文档，支持图片本地化保存与自定义 YAML 模板。

### 2. 深度批注与转换
*   **MarkItDown Importer**
    *   **核心功能**：支持将外部 PDF、网页、视频链接等直接拖拽至编辑器，自动转换为纯文本的 Markdown 文件。
*   **PDF++ / Annotator**
    *   **核心功能**：在 Obsidian 内对 PDF 附件进行高亮与批注，并将这些批注一键导出为独立的 Markdown 笔记。

### 3. AI 提效与白板视觉
*   **Copilot**
    *   **核心功能**：Obsidian 排名第一的 AI 插件。可在笔记侧边栏直接对话，支持单篇笔记的快速改写、语法纠错、总结以及添加自定义快捷提示词。
*   **Claudian / Terminal**
    *   **核心功能**：在 Obsidian 内部集成终端/对话框，无需离开软件即可直接调用本地的 Claude Code 等智能体进行跨文件扫描、总结与归类。
*   **Excalidraw**
    *   **核心功能**：主打手绘风格的无限画布白板。支持图表绘制、思维导图、脑暴整理，并可通过外部 Agent 技能（如 `excalidraw-diagram`）一键生成精美画布。

要让 AI 对整个文件夹进行综合分析，单靠简单的单篇对话不够，需要借助以下工具：

| 插件名称 | 核心功能 | 跨文档整合场景 |
| --- | --- | --- |
| **Smart Connections** | 全局向量化索引 (Embedding) | **全局语义关联** 。它会把整个文件夹（或整个 Vault）计算为向量库，直接在侧边栏对整个文件夹提问：“ *结合我文件夹里所有关于 RAG 的笔记，帮我梳理出一份包含课程、文章和聊天记录的完整知识图谱。* ” |
| **Copilot (Vault / Folder 模式)** | 上下文增强 | 支持在 Prompt 中使用 `@Folder` 语法，直接选中某个文件夹下的多篇资料作为上下文，进行集中提炼与对比分析。 |
| **Dataview** | 动态数据汇总 | 类似 SQL 语法，自动把分散在不同文件夹、带有所需标签（如 `#topic/rag` ）的笔记拉成清单表格。 |
| **Obsidian Canvas (白板)** | 可视化知识卡片拼贴 | 将不同来源的节点卡片拖入同一白板，通过连线与分组构建全局知识架构。 |

## 常用技巧

### 1. 双向链接（双链）与反链
*   **双链 `[[笔记名称]]`**：快速创建指向特定笔记的超链接，打破文件夹的孤立限制。
*   **出链（Outlinks）**：当前笔记引用的其他笔记，用于延展思路。
*   **反链（Backlinks）**：提到当前笔记的所有其他笔记，自动形成完整的来龙去脉。
*   **知识自生长**：随着双链的不断建立，零碎的笔记在彼此引用中逐渐交织，自动生成可视化的“关系图谱”，实现知识复利。

### 2. 工作区排版与布局保存
*   **多窗口排版**：利用多标签页拆分功能，将工作区分为“左侧查阅参考资料”、“中间写稿/笔记草稿”、“右侧查看局部关系图谱或反链”。
*   **一键恢复布局**：在“核心插件”中启用「工作区」，可将当前排版保存为特定工作模式（如“写稿模式”），后续可一键恢复，免去重复调整窗口的麻烦。

## 多端同步

### 1. 三大主流免费同步方案
*   **iCloud 方案**：适合苹果生态用户（Mac + iPhone + iPad）或配合 Windows 客户端使用，简单无感。
*   **坚果云（WebDAV）方案**：适合轻量笔记用户，多端跨平台通用，通过第三方插件实现增量同步。
*   **Syncthing / 微力同步方案**：重度用户、大附件及多设备用户的毕业级点对点（P2P）局域网同步，数据不经云端，速度极快。

### 2. 避免冲突与防丢失法则
*   **目录层级一致性**：各设备创建仓库时，必须确保文件夹层级与命名完全一致，否则正文虽能同步，但附件链接会因路径不符而失效。
*   **开启版本回收站（核心防丢项）**：在同步工具（如 Syncthing/微力同步）中，务必开启“时间回收站”或“版本控制”并建议保留时长设为 60 天，防止同步冲突导致笔记被误删。
*   **禁止多套同步并行**：千万不要对同一个仓库同时使用 iCloud 和 Syncthing 等多套系统同步，否则极易引发冲突导致数据混乱。
