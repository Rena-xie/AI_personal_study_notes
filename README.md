# AI 应用开发学习笔记

围绕 AI 应用开发整理的系统性学习笔记，内容沿着以下主线展开：

`学习路径与岗位画像 → Python / LLM 基础 → RAG 全链路 → Agent 工程化 → AI 应用工程落地`

本仓库展示 AI 应用开发学习主线下的 5 个模块、40 篇笔记。内容聚焦概念之间的依赖关系、方案选型、参数权衡、评估方法与生产环境中的工程约束，并配合知识图谱、架构图、流程图和对比表进行说明，适合快速了解我的知识结构与技术思考过程。

建议按 `01 → 02 → 03 → 04 → 05` 的顺序阅读，也可以直接通过目录进入感兴趣的主题。

### 02 基础知识

从 Python 编程基础与抽象能力出发，结合 LLM 的 Token、上下文窗口、生成参数和模型选型，建立 AI 应用开发的前置知识。

**LLM 基础**

* [LLM大模型](LLM大模型.md)：大模型生成机制、Token 与上下文窗口、Temperature 等生成参数，以及主流模型选型。

**Python 工程基础**

* [01 数据类型与变量](02基础知识/Python/01_数据类型与变量.md)：内置数据类型、字符串与编码，以及 list、tuple、dict、set 的使用。
* [02 条件判断与模式匹配](02基础知识/Python/02_条件判断与模式匹配.md)：if-elif-else、match-case、循环控制及其选择依据。
* [03 函数](02基础知识/Python/03_函数.md)：函数调用与定义、参数传递机制和递归。
* [04 高级特性](02基础知识/Python/04_高级特性.md)：切片、迭代、列表生成式、生成器与迭代器，并映射到流式响应、批量处理等 AI 场景。
* [05 高阶函数](02基础知识/Python/05_高阶函数.md)：map、reduce、filter、sorted、闭包、lambda、装饰器与偏函数在 AI 工程中的应用。
* [06 模块与包](02基础知识/Python/06_模块与包.md)：模块导入、第三方依赖管理与 AI 工程中的代码组织方式。
* [07 面向对象编程](02基础知识/Python/07_面向对象编程.md)：封装、继承、多态、对象检视与属性机制，以及多模型供应商抽象等落地场景。
* [08 面向对象高级编程](02基础知识/Python/08_面向对象高级编程.md)：`__slots__`、`@property`、Mixin、魔术方法、Enum 与元类。
* [09 错误、调试、测试](02基础知识/Python/09_错误、调试、测试.md)：异常处理、调试、单元测试与 doctest，建立代码质量保障能力。
* [10 IO 编程](02基础知识/Python/10_IO编程.md)：上下文管理、流式读取、编码容错、二进制 IO 与日志刷盘，并落到 RAG、Agent 工程场景。

### 03 RAG 工程

覆盖 RAG 从离线知识库构建到在线检索生成的完整流程，重点讲解数据解析、文本分块、向量化与索引构建、查询工程，以及混合检索、重排和上下文构建。

* [01 数据解析策略](03RAG工程/01_数据解析策略.md)：预检路由、解析管道、元数据与文本去噪、解析工具选型矩阵及抽样检查。
* [02 文本分块策略](03RAG工程/02_文本分块策略.md)：分块大小权衡、递归 / 语义 / 父子 / 句窗口切分、生产策略组合、企业落地案例与主流框架解析。
* [03 向量化、索引构建及数据库](03_向量化、索引与数据库.md)：Embedding 与相似度度量、RAG 语义检索工作流、向量数据库数据模型与选型、Milvus 物理结构及索引机制。
* [04 查询工程](03RAG工程/04_查询工程.md)：查询重构六大技术、检索评估、元数据过滤与结构化查询扩展、智能查询路由。
* [05 检索与重排](03RAG工程/05_检索与重排.md)：稠密与稀疏混合检索、异构得分融合、两阶段重排、Reranker 选型、上下文构建与压缩、有据生成及工业级双流水线。

### 04 智能体工程
