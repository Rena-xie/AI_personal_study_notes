# AI 应用开发学习笔记

围绕 AI 应用开发整理的系统性学习笔记，内容沿着以下主线展开：

`Python / LLM 基础 → RAG 全链路 → Agent 工程化`

笔记聚焦概念之间的依赖关系、方案选型、参数权衡、评估方法与生产环境中的工程约束，并配合知识图谱、架构图、流程图和对比表进行说明，适合快速了解我的知识结构与技术思考过程。

建议按 `02 → 03 → 04` 的顺序阅读，也可以直接通过目录进入感兴趣的主题。

### 02 基础知识

**LLM 基础**

* [LLM](02基础知识/LLM.md)：大模型生成机制、Token 与上下文窗口、Temperature 等生成参数，以及主流模型选型。

**Python 工程基础**

* [Python 学习路线](02基础知识/Python/要学哪些.md)：梳理基础语法、函数式编程、OOP、异常处理、并发、异步与数据库等内容的掌握优先级。
* [数据类型与变量](02基础知识/Python/数据类型与变量.md)：内置数据类型、字符串编码，以及 list、tuple、dict、set 的使用。
* [条件判断与模式匹配](02基础知识/Python/条件判断与模式匹配.md)：if-elif-else、match-case、循环控制及其选择依据。
* [函数](02基础知识/Python/函数.md)：函数调用与定义、参数传递机制和递归。
* [高级特性](02基础知识/Python/高级特性.md)：切片、迭代、列表生成式、生成器与迭代器，并映射到流式响应、批量处理等 AI 场景。
* [高阶函数](02基础知识/Python/高阶函数.md)：map、reduce、filter、sorted、闭包、lambda、装饰器与偏函数在 AI 工程中的应用。
* [模块与包](02基础知识/Python/模块与包.md)：模块导入、第三方依赖管理与 AI 工程中的代码组织方式。
* [面向对象编程](02基础知识/Python/面向对象编程.md)：封装、继承、多态、对象检视与属性机制，以及多模型供应商抽象等落地场景。
* [面向对象高级编程](02基础知识/Python/面向对象高级编程.md)：`__slots__`、`@property`、Mixin、魔术方法、Enum 与元类。
* [错误、调试、测试](02基础知识/Python/错误、调试、测试.md)：异常处理、调试、单元测试与 doctest，建立代码质量保障能力。

### 03 RAG 工程

覆盖 RAG 从离线知识库构建到在线检索生成的完整流程，并延伸到自动化评测、可观测性运维与系统编排。

* [RAG 全栈技术](03RAG工程/RAG全栈技术.md)：RAG 核心概念与术语、直连大模型的核心瓶颈、全栈技术选型、双流水线，以及 Agentic RAG、Self-RAG、GraphRAG 等扩展范式。
* [01 数据解析策略](03RAG工程/01_数据解析策略.md)：格式预检与算力隔离、结构化提取、元数据、无损清洗、解析工具选型与可调参数。
* [02 文本分块策略](03RAG工程/02_文本分块策略.md)：Chunk Size 与 Overlap 权衡、递归/语义/结构切分、父子块、句窗口、Contextual Retrieval 与分块质量评估。
* [03 向量化原理及选型](03RAG工程/03_向量化原理及选型.md)：Embedding、相似度度量、模型与向量数据库选型、HNSW/ANN、Recall@K 与多模态嵌入。
* [04 查询工程与混合检索重排](03RAG工程/04_查询工程与混合检索重排.md)：Query 重构与路由、BM25 与稠密检索、RRF/加权融合、Cross-Encoder 重排、上下文构建与有据生成。
* [05 自动化评测](03RAG工程/05_自动化评测.md)：评估驱动开发理念、评估维度与黄金测试集、核心量化指标、评估工作流与工具链。
* [06 LLMOps 与可观测性运维](03RAG工程/06_LLMOps与可观测性运维.md)：链路可观测性、故障根因分析、数据飞轮、高性能服务、有状态运行、安全权限与版本运维。
* [07 系统编排与工具链接](03RAG工程/07_系统编排与工具链接.md)：RAG 三条流水线、编排框架选型、工具调用、状态与执行控制、系统接口设计与 Agentic RAG 架构。

### 04 智能体工程

从 Workflow 与 Agent 的边界和选型开始，逐步展开 Agent 的运行时、工具生态、决策模式、上下文、记忆与工作流编排。

* [00 Workflow 与 Agent 的对比与选型](04智能体工程/00_Workflow%20与%20Agent%20的对比与选型.md)：本质差异、适用边界与案例对比，以及 Workflow 控制主流程、Agent 负责局部决策的融合架构。
* [01 Agent 基础认知与运行架构](04智能体工程/01_Agent基础认知与运行架构.md)：Agent 定义、Agent Loop、LLM/Runtime/Tools/Context/State 五个核心组件与自主性控制。

* [03 Agent 决策范式与工作流模式](04智能体工程/03_Agent%20决策范式与工作流模式.md)：ReAct、Plan-and-Solve、Reflection，以及 Prompt Chaining、Routing、Parallelization、Orchestrator-Workers、Evaluator-Optimizer。

* [05 记忆系统与工程](04智能体工程/05_记忆系统与工程.md)：短期与长期记忆、写入和检索机制、更新冲突、去重与版本管理、过期删除以及跨 Session 记忆设计。
* [06 外部工具集成](04智能体工程/06_外部工具集成.md)：四层集成架构、高质量 Tool 接口设计、权限与安全边界、工具返回数据的上下文治理。
* [07 工作流编排](04智能体工程/07_工作流编排.md)：核心工作流范式、控制机制、异常分支、重试恢复与动态重新规划。
