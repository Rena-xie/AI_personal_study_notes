# AI 应用开发学习笔记

围绕 AI 应用开发整理的系统性学习笔记，内容沿着以下主线展开：

`学习路径与岗位画像 → Python / LLM 基础 → RAG 全链路 → Agent 工程化`

本仓库展示 AI 应用开发学习主线下的 4 个模块、29 篇笔记。内容聚焦概念之间的依赖关系、方案选型、参数权衡、评估方法与生产环境中的工程约束，并配合知识图谱、架构图、流程图和对比表进行说明，适合快速了解我的知识结构与技术思考过程。

建议按 `01 → 02 → 03 → 04` 的顺序阅读，也可以直接通过目录进入感兴趣的主题。

* [09 错误、调试、测试](02基础知识/Python/09_错误、调试、测试.md)：异常处理、调试、单元测试与 doctest，建立代码质量保障能力。

### 03 RAG 工程

覆盖 RAG 从离线知识库构建到在线检索生成的完整流程，并延伸到自动化评测、可观测性运维与系统编排。

* [RAG 相关术语](03RAG工程/相关术语.md)：覆盖数据接入与解析、切片、Embedding、向量数据库、查询工程、检索、融合与重排、生成、评测、系统编排、可观测性及安全运维的核心术语。
* [01 数据解析策略](03RAG工程/01_数据解析策略.md)：格式预检与算力隔离、结构化提取、元数据、无损清洗、解析工具选型与社区评测。
* [02 文本分块策略](03RAG工程/02_文本分块策略.md)：Chunk Size 与 Overlap 权衡、递归 / 语义 / 结构切分、父子块、句窗口、Contextual Retrieval 与分块质量评估。
* [03 向量化原理及选型](03_向量化原理及数据库.md)：Embedding、相似度度量、模型与向量数据库选型、HNSW / ANN、Recall@K 与多模态嵌入。
* [04 查询工程与混合检索重排](04_查询工程.md)：Query 重构与路由、BM25 与稠密检索、RRF / 加权融合、Cross-Encoder 重排、上下文构建与有据生成。
* [05 自动化评测](05_自动化评测.md)：评估驱动开发理念、评估维度与黄金测试集、核心量化指标、评估工作流与工具链。
* [06 LLMOps 与可观测性运维](06_LLMOps与可观测性运维.md)：链路可观测性、故障根因分析、数据飞轮、高性能服务、有状态运行、安全权限与版本运维。
* [07 系统编排与工具链接](06_系统编排.md)：RAG 三条流水线、编排框架选型、工具调用、状态与执行控制、系统接口设计与 Agentic RAG 架构。

### 04 智能体工程

从 Workflow 与 Agent 的边界和选型开始，逐步展开 Agent 的运行时、工具生态、决策模式、上下文、记忆与工作流编排。

* [07 工作流编排](04智能体工程/07_工作流编排.md)：核心工作流范式、控制机制、异常分支、重试恢复与动态重新规划。
