Skill 把“专家决策规则”提供给 Agent，让 Agent 按规则做决定。

阅读skill的顺序：

第1步：先看 README.md
重点看：
- Skill解决什么问题？
- 输入是什么？
- 输出是什么？
- 使用场景是什么？
- 有没有示例？

要明白 “这个 Skill 在 AI 系统里扮演什么角色？”

第2步：看 SKILL.md
- 知道什么情况下 Agent 应该调用它？输入是什么？
- 阅读Hard rules，知道专家经验规则
- Workflow，Agent拿到任务以后，会按照什么顺序工作
- References，看这个 Skill 把哪些知识拆出去，
第3步：看目录结构
第4步：看 references（规则文件），学习决策逻辑
第5步：看 scripts
